# NOVA Training Institute

تطبيق PHP/MySQL لمعهد NOVA، ويشمل واجهات الزوار والمستخدمين ولوحة الإدارة وإدارة المستخدمين والدورات والتسجيلات والرسائل.

## الإعداد

1. أنشئ قاعدة MySQL على الاستضافة.
2. استورد الملف `database/schema.sql` من phpMyAdmin.
3. اضبط متغيرات البيئة التالية في `includes/config.php` أو في إعدادات الاستضافة: `NOVA_DB_HOST` و`NOVA_DB_USER` و`NOVA_DB_PASS` و`NOVA_DB_NAME` و`NOVA_SITE_URL`.
4. أنشئ أول حساب مستخدم من صفحة التسجيل، ثم فعّله من قاعدة البيانات أو لوحة الإدارة بعد إنشاء مدير آمن يدوياً.

## ملاحظات الإنتاج

تم تعطيل عرض أخطاء PHP في وضع الإنتاج، واستخدام PDO مع prepared statements، وتجزئة كلمات المرور بواسطة `password_hash`، وتقييد جلسات الدخول بخصائص HttpOnly وSameSite، وحذف أداة إنشاء المدير الافتراضي من النسخة المنشورة. يجب عدم رفع كلمات المرور أو ملفات الإعداد المحلية إلى GitHub.
